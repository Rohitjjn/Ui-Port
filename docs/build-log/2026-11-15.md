### Hits and misses worth remembering

- `node --test tests/unit` does not expand a directory on Node 22; `node --test "tests/unit/*.test.mjs"`
  does. The npm scripts use the glob form.
- `write EPIPE` when piping a script's output into `head` crashed `resolve-versions.mjs`; it now writes
  everything in one guarded write.
- The registry's abbreviated metadata (`application/vnd.npm.install-v1+json`) has no publish times, so
  the "two weeks old" policy could not be enforced. Switched to the full document; that is how
  Playwright 1.65.1 (1 day old) was replaced by 1.64.1 (31 days old).
- Piping `head` into a script whose stdout is a table is not worth the fragility; scripts now either
  print one JSON blob or one complete table.

## Phase B.4 — the port loop, on real CI

The earlier conclusion ("Actions cannot be triggered from this session") turned out to be wrong in
the way that matters: workflows cannot be *dispatched*, but they run on push, and they have been
running. Everything below is from runs, not from a local guess.

### The harness had to be built before anything could be measured

1. Paparazzi renders on the JVM, so `testbed/SimpMusic/uiPortScreenshots` exists as its own module.
   Five attempts got it compiling before it rendered: `DeviceConfig.density` is
   `com.android.resources.Density` (an enum, not a float, not `androidx.compose.ui.unit`),
   `screenRound` is `ScreenRound.NOTROUND`, there is no `statusBarHeight` parameter, and
   `screenWidth/screenHeight` are pixels — so the PNG extent is dp x density.
2. Paparazzi 2.0.0-alpha05.1 **clamps a snapshot to 1000 px on its long edge**. A 2x 786x1704
   render is not possible; a 2x request silently produced 461x1000. Both sides are compared at 1x
   (393x852) as a result, and the renderer uses `xdpi/ydpi = 160` with density 1.0 to get one pixel
   per dp.
3. `capture-reference.mjs` takes DPR from `--viewports`, not from the capture spec, so the same 1x
   file has to be passed to `plan-capture.mjs` **and** to `capture-reference.mjs`. Passing it to
   only the planner silently did nothing.

### Reading a diff without being able to download it

Logs and artifacts are blob-hosted and unreadable from here, and only the annotations API works. So
the diagnostics had to be text: `scripts/diff-map.mjs` (coarse divergence map, surface bands, probes)
and `scripts/annotate-geometry.mjs` (compact digest of the reference's boxes), both published as
annotations. Then three more lessons, each costing a run:

- An annotation keeps **only its first line** — multi-line JSON printed as a single `{`.
- GitHub keeps only the **first ten annotations a step emits**, and the annotations API returns 30
  per page. Seventeen notices of diff maps meant the per-screen score lines were never visible.
- Gradle swallows a test's stdout unless test logging is raised for the task, so the layout boxes had
  to be written to a file and read from there.

### What the numbers did

`home` went 80.12% → 94.96% in three steps: porting the shell (the reference is the whole
AppShell, not the routed screen), then placing the screen on the reference's measured grid, then
fixing the individual blocks the probes named. After that it went backwards twice — 12px side
insets (85.15%) and the full webfont bundle (89.21–89.26%) — and the best state was restored rather
than left as the last thing tried.

The font experiment produced the most useful negative result of the phase: **the capture blocks
every non-same-origin request, so the prototype's Google Fonts never load and the reference is the
browser's fallback stacks**. Bundling Instrument Serif and Inter made the port less like the
reference. The bundled files and their OFL licences stay in the repository with the measurement
recorded in `docs/LIMITS.md`, because the decision belongs to the capture configuration.

### Where it stopped

Current scores, all from run 43835731014 and all below the 98.5% floor: `home` 94.858% /
SSIM 0.738, `library` 86.916% / 0.565, `nowplaying` 79.303% / 0.431. Geometry is unmeasured on both
sides of the comparison (`-`), and the candidate boxes are the interim substitute.

Two process failures worth naming: the local branch ref drifted to the base commit twice, and both
times the push was rejected correctly and resolved by `git rebase`, never by force. And the
`nowplaying` score only exists because the capture reported `state-not-reproducible` twice instead
of writing a plausible screenshot of the wrong page.
