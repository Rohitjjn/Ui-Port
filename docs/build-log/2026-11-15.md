### Built, in order

1. **Foundations** — `package.json` (pinned devDeps), `.gitignore`, `LICENSE` (MIT), README, config
   (`tools.json` with resolution dates and an age policy, `viewports.json`, `thresholds.json`),
   plugin manifest + marketplace.
2. **Libraries** — `fs-utils` (glob matcher included), `state` (schema, atomic writes, migration,
   quarantine, per-screen status, iteration counters), `worklog` (six sections, changelog, staleness),
   `answers` (headless mode with strict validation), `preflight` (environment snapshot, mode
   classification, project-case detection, tool plan).
3. **CLI** — one entry point for every operation, so skills never re-implement logic.
4. **Hooks** — four, each a thin wrapper over a pure decision module. First run of the test suite hung
   for five minutes: importing `hooks/syntax-check.mjs` executed it and it blocked reading stdin.
   Fixed by moving the logic to `hooks/lib/syntax.mjs`; the wrapper stays a script.
5. **Unit tests** — 73 at that point (state, preflight, answers, hooks, worklog), all green.
6. **Prototype scanner** — routes, screens, components, stores, libraries, tokens, fonts, motion,
   assets, data shapes. Iterated against the real prototype: fixed route parsing (nested route arrays,
   `<Navigate>` redirects, layout routes with `children`), fonts leaking `var()` references, design
   tokens losing the light palette because the dark block overwrote it, zustand stores wrapped in
   `persist(...)` reading as empty, and imports missing `.ts` files (that is where the stores live).
   Final: 23 screens, 5 libraries, 4 stores, both font families, `darkMode: class-toggle`.
7. **App scanner** — compiled with the real SimpMusic tree (1160 Kotlin files, 34 screens, 35
   ViewModels, 64 engine entry points). Fixed: composables not found when annotations were on separate
   lines; `hasState` false because the function-body scan hit a default lambda `= {}` inside the
   parameter list; `usesViewModel` missing `koinInject()`; ViewModel deps/states empty for the
   `): BaseViewModel() {` form; and the serious one — **engine globs protected whole modules**, which
   would have protected `composeApp/ui/**` and made the plugin refuse to do its own job. Now a
   directory becomes a glob only when every Kotlin file in it is engine code; mixed directories are
   protected file by file, and a unit test asserts the UI package is never globbed.
8. **Diff engine** — pixelmatch + SSIM + geometry + masks + heat map + noise floor + acceptance
   decisions. 29 tests with synthetic images: identical = 100%, 3px shift detected, colour change
   detected, masks make a region disappear from the score, 1dp tolerance absorbs sub-pixel noise, 5dp
   shift reported with the element name, iteration-cap and floor logic, noise-floor adjustment.
9. **Capture** — Playwright script with deterministic mode (frozen animations, pinned `Date`, seeded
   `Math.random`, network off, fonts awaited, caret hidden, scrollbars hidden, DOM geometry dump) plus
   `plan-capture.mjs`. Could not be executed here: Chromium cannot be downloaded (D3). It exits with
   code 7 and a message that routes the work to CI, which is the designed behaviour.
10. **Skills, agents, commands** — 11 skills with references, 4 agents, 4 commands, written to be
    short and to defer all measurement to scripts.
11. **Validation** — `validate-plugin.mjs` (manifest, frontmatter, hook paths, config schema, every
    referenced script exists, no absolute machine paths) and `lint-markdown.mjs` (headings, fences,
    relative links, trailing whitespace). Both green; they immediately caught 8 real problems
    (3 missing reference files, 3 missing scripts, invalid `allowed-tools` frontmatter, an absolute
    path in my own validator).
12. **Packaging** — `package-zip.mjs` (excludes build output/caches/secrets, includes the worklog,
    refuses oversized archives) and `verify.mjs` (records every check with command, exit code and
    duration). 19 CLI-level tests including a real ZIP inspected with `unzip -Z1`.
13. **CI** — `ci-static.yml` and `ci-unit.yml` (ubuntu/windows/macos matrix).

### Hits and misses worth remembering

- `node --test tests/unit` does not expand a directory on Node 22; `node --test "tests/unit/*.test.mjs"`
  does. The npm scripts use the glob form.
- `write EPIPE` when piping a script's output into `head` crashed `resolve-versions.mjs`; it now writes
  everything in one guarded write.
- The registry's abbreviated metadata (`application/vnd.npm.install-v1+json`) has no publish times, so
  the "two weeks old" policy could not be enforced. Switched to the full document; that is how
  Playwright 1.65.1 (1 day old) was replaced by 1.64.1 (31 days old).
- Piping `head` into a script whose stdout is a table is not worth the fragility; scripts now either
  print one JSON blob or one complete table.

### Where it stopped

GitHub Actions cannot be triggered from this session (public repo, write access verified by creating
and deleting a probe workflow file, but `/actions/workflows` stays empty and `/actions/permissions` is
403). Combined with no JDK and no browser, the three things the prompt wants as evidence — a green
baseline build, a real Playwright capture and a real Compose screenshot diff — cannot happen here.
`docs/PLAN.md` records this as D1–D3 with the exact next steps.
